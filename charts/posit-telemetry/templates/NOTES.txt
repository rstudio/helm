Agents send Opentelemetry data (OTLP HTTP) to:

    http://{{ include "posit-telemetry.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}

Set that address as each agent's `[Server] Address`, with `[Server] Enabled = false`.

Query Clickhouse with:

    kubectl exec -it -n {{ .Release.Namespace }} -c clickhouse statefulset/{{ include "posit-telemetry.fullname" . }} -- \
      sh -c 'clickhouse-client --user telemetry --password "$CLICKHOUSE_TELEMETRY_PASSWORD" --database telemetry'
